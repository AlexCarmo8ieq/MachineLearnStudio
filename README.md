# MachineLearnStudio
Leaning about Machine Learn


1. Criar um Workspace do Azure Machine Learning
Acesse o Portal Azure.
Pesquise por Azure Machine Learning.
Clique em Create.
Configure:
Subscription
Resource Group
Workspace Name
Region
Clique em Review + Create.
2. Acessar o Azure Machine Learning Studio

Após a implantação:

Abra o Workspace.
Clique em Launch Studio.
Acesse o ambiente web do Azure Machine Learning.
